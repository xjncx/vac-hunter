# JobSearcher для HeadHunter

Локальный веб-сервис, который ищет вакансии через официальный API HeadHunter,
ранжирует их по навыкам и стоп-словам и готовит отклик. По умолчанию работает
в безопасном режиме `dry-run`: ничего не отправляет на HH.

## Запуск

Нужен Python 3.11+ (на Windows установите его с [python.org](https://www.python.org/downloads/windows/),
если команда `py` ещё не запускается).

```powershell
Copy-Item .env.example .env
.\run.ps1
```

Откройте `http://localhost:8000`.

Анонимный поиск работает без OAuth. Чтобы подключить аккаунт:

1. Зарегистрируйте приложение на [dev.hh.ru](https://dev.hh.ru/).
2. Укажите callback `http://localhost:8000/oauth/callback`.
3. Заполните в `.env` `HH_CLIENT_ID`, `HH_CLIENT_SECRET` и корректный
   `HH_USER_AGENT` с вашим реальным контактным email. Адреса `example.com` HH
   отклоняет. Для анонимного поиска достаточно заполнить только `HH_USER_AGENT`.
4. Перезапустите сервис и нажмите «Подключить HeadHunter».

Для реальных откликов отдельно установите `HH_SEND_ENABLED=true`. До этого
момента кнопка лишь записывает намерение в локальную SQLite-базу. Перед
отправкой сервис проверяет, что отклика ещё не было и резюме входит в список
подходящих для вакансии.

## Проверка

```powershell
py -m unittest discover -s tests -v
```

## Ограничения MVP

- Нет обхода CAPTCHA, лимитов или защит площадки.
- Вопросы работодателя пока не заполняются автоматически.
- Токены хранятся в локальной SQLite-базе; для публичного размещения нужно
  шифрование секретов, HTTPS и нормальная пользовательская авторизация.
- Массовая отправка намеренно отсутствует: каждый отклик подтверждается вручную.

Документация: [OpenAPI HeadHunter](https://api.hh.ru/openapi/redoc),
[официальный репозиторий API](https://github.com/hhru/api).
